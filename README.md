# THE WORLD IS YOURS

> "First you get the money, then you get the power." — Tony Montana

App de gerenciamento de vendas e meta financeira com tema Scarface e cobrança no estilo Whiplash.

## Meta

R$ 100.000 líquidos em 90 dias, vendendo dois produtos:

- **Tapete** — R$ 137 + upsell de R$ 26 (com 20% de comissão pra atendente)
- **Colágeno** — R$ 197

## Como usar

1. Abra `index.html` no navegador.
2. Vá em **Configurações** e ajuste data de início, meta, prazo e taxas.
3. Toda noite registre as vendas e o gasto em ads do dia.
4. O Fletcher te cobra. A quota diária se ajusta sozinha.

## Demo ao vivo

Se publicado via GitHub Pages: https://japagostoso.github.io/100K-TONY/

## Stack

HTML + CSS + JS puro. Zero dependências além de Google Fonts. Dados salvos no `localStorage` do navegador.

## Tema

Scarface (Miami 1983) + Whiplash (J.K. Simmons modo Fletcher). Sem mimimi.
